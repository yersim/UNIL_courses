## A Gentle Introduction to Decision Trees and Random Forests with Python and R course

> Objectives

Acquire the key competencies needed to apply decision tree and random forest methods to simple datasets

> Content
- Understand how the decision tree and random forest algorithms work
- Run simple machine learning codes in Python or R
- Be able to choose properly the hyper-parameters of the models

## Biodiversity bioinformatics: from large-scale phylogenomics to gene families and functions

> Day 1

Introduction to molecular evolution & phylogenetics

> Day 2

Orthology-focused arthropod comparative genomics

> Day 3

 Duplication of genes and genomes, expression

## Spring School Bioinformatics and Computational Approaches in Microbiology

> Goal

Provide PhD students and postdocs with theoretical and mostly hands-on knowledge on selected topics about microbiome and antibiotics resistance.

> Project 3

Profiling and modeling the colorectal cancer microbiome.

## NGS - Quality Control, Alignment, Visualisation

> Objectives

Introduce the most used sequencing technologies and explain their concepts. Using different datasets, practice quality control, alignment of reads to a reference genome and visualize the output.

> Content
- understand the basics of the different NGS technologies
- perform quality control for better downstream analysis
- align reads to a reference genome
- visualize the output.
